# ROS2 机器人传感器监控系统 - 项目说明书

 1. 项目概述
本项目是一个基于ROS2（Humble）的机器人传感器监控系统，涵盖了机器人软件开发的核心环节。

 2. 系统架构
系统采用分布式节点架构：
 sensor_publisher → 发布传感器数据
 sensor_subscriber → 接收并处理数据
 tf2_broadcaster → 广播坐标变换
 tf2_listener → 查询坐标变换
 service_server → 提供坐标查询服务

 3. 通信机制
 话题通信: /sensor_data (传感器数据)
 服务通信: /get_transform_service (坐标查询)
 TF2通信: map→base_link→laser_link (坐标变换树)

 4. 技术亮点
 自定义消息/服务接口
 消息收发工具类封装
 TF2多传感器时空同步
 异步服务调用
 一键部署脚本

 5. 运行环境
 操作系统: Ubuntu 22.04 (WSL2)
 ROS2版本: Humble
 编译器: gcc 11.4
 构建工具: colcon
